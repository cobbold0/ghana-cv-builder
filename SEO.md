# Ghana CV Builder — SEO Strategy

## 1. SEO objective

Organic search should become the primary user acquisition channel for Ghana CV Builder.

The goal is not simply to rank the homepage.

The goal is to build a collection of useful pages that answer different CV-related searches and naturally lead users into the CV builder.

Target market initially:

- Ghana
- Ghanaian students
- Ghanaian graduates
- Ghanaian job seekers

The architecture should allow expansion to other African countries later.

## 2. Search intent strategy

Prioritize search intent over keyword stuffing.

The main categories are:

### Transactional

People who want to create a CV. Examples:

- CV builder
- online CV builder
- free CV builder
- create CV online
- CV maker

### Template searches

People looking for a template. Examples:

- CV template
- free CV template
- professional CV template
- CV template Ghana
- modern CV template

### Example searches

People looking for examples. Examples:

- CV example
- CV examples Ghana
- graduate CV example
- student CV example
- internship CV example
- professional CV example

### Informational searches

People looking for guidance. Examples:

- how to write a CV
- how to write a CV in Ghana
- how to write a professional CV
- what to include in a CV
- CV format
- CV tips

## 3. Primary landing pages

The application should support useful SEO landing pages such as:

```text
/
/cv-builder
/cv-templates
/cv-examples
/cv-format
/cv-template-ghana
/professional-cv
/graduate-cv
/student-cv
/internship-cv
/how-to-write-a-cv
```

Do not create all pages automatically if they do not contain genuinely useful content.

## 4. Homepage SEO

The homepage should target the broad product intent around:

- CV builder
- create a CV
- professional CV

The page should clearly communicate:

> Create a professional CV in minutes.

It should provide a strong CTA to the builder.

Suggested structure:

```text
Hero
↓
Create CV CTA
↓
How it works
↓
Template previews
↓
Why use the builder
↓
CV examples/resources
↓
FAQ
↓
Final CTA
```

Do not turn the homepage into a keyword-heavy article.

## 5. CV template pages

Create useful template discovery pages. Example:

```text
/cv-templates
```

This page should allow users to:

- See available templates
- Understand template styles
- Choose a template
- Start creating a CV

Each template should have a useful description.

Potential future individual pages:

```text
/cv-templates/modern
/cv-templates/classic
/cv-templates/minimal
/cv-templates/graduate
```

Only index individual template pages when they provide meaningful unique content.

## 6. CV example pages

Create useful examples for different user groups. Examples:

```text
/cv-examples
/cv-examples/graduate
/cv-examples/student
/cv-examples/internship
/cv-examples/software-developer
/cv-examples/accountant
/cv-examples/teacher
```

Examples should be clearly identified as examples.

Do not invent real people's identities, employment history or qualifications.

Use fictional example data where necessary.

## 7. Ghana-specific SEO

Ghana-specific pages should provide genuinely Ghana-relevant information.

Potential pages:

```text
/cv-template-ghana
/cv-format-ghana
/how-to-write-a-cv-in-ghana
/graduate-cv-ghana
```

Use Ghanaian examples where appropriate. Examples may include:

- Ghanaian locations
- Ghanaian universities
- Ghanaian phone number formats
- Local job-search terminology

Do not claim that a particular CV format is universally required by Ghanaian employers unless reliable evidence supports the claim.

## 8. Informational content

Create useful articles/resources around CV creation.

Potential topics:

```text
How to Write a CV
How to Write a CV in Ghana
How to Write a CV With No Experience
How to Write a Graduate CV
How to Write an Internship CV
How to Write a Professional Summary
How to Describe Work Experience on a CV
CV Mistakes to Avoid
What Skills Should You Put on a CV?
CV vs Resume
How Long Should a CV Be?
```

Each article should answer the user's actual question.

Do not produce generic AI-generated filler.

## 9. Internal linking

Build a deliberate internal-linking structure. Example:

```text
Article
  ↓
CV example
  ↓
CV template
  ↓
CV builder
```

Another example:

```text
Graduate CV article
  ↓
Graduate CV example
  ↓
Graduate template
  ↓
Create CV
```

Relevant pages should link to one another naturally.

Do not add excessive links.

## 10. Calls to action

SEO pages should naturally direct users toward the product. Examples:

- Create your CV
- Start building your CV
- Use this template
- Build your professional CV

The CTA should be relevant to the page.

Do not use aggressive popups immediately after page load.

## 11. Metadata

Every indexable page should have:

- Unique title
- Unique meta description
- Canonical URL
- Appropriate Open Graph metadata

Titles should describe the actual page.

Avoid:

```text
CV Templates | CV Templates | Free CV Templates | Best CV Templates
```

Prefer natural titles such as:

```text
Professional CV Templates — Free Online CV Builder
```

## 12. Heading structure

Each page should have:

- One clear H1
- Logical H2 sections
- H3 subsections where useful

Do not use headings purely for styling.

## 13. Structured data

Use structured data where it genuinely applies.

Potential schema types:

- WebSite
- WebApplication
- Article
- BreadcrumbList
- FAQPage where appropriate and compliant with current search-engine guidelines

Do not add irrelevant or misleading structured data.

## 14. Sitemap

Generate a sitemap containing important indexable URLs.

Do not include:

- Private builder sessions
- Temporary URLs
- Duplicate URLs
- Pages intentionally marked noindex

Update the sitemap automatically when content changes where practical.

## 15. Robots

Configure robots.txt appropriately.

Do not accidentally block:

- Homepage
- SEO landing pages
- Template pages
- Example pages
- Important resources

Avoid exposing private application routes to search engines.

## 16. Canonical URLs

Use canonical URLs to avoid duplicate-content problems.

Normalize:

- Trailing slash behavior
- Query parameters
- Duplicate routes
- Template variations

Builder state should not create thousands of indexable URLs.

## 17. Programmatic SEO

Programmatic SEO may be used later.

Potential expansion:

```text
/cv-examples/[profession]
/cv-templates/[profession]
/cv-examples/[experience-level]
```

Examples:

```text
/cv-examples/software-developer
/cv-examples/accountant
/cv-examples/teacher
/cv-examples/marketing-manager
```

Only generate these pages when each page has meaningful, useful content.

Do not create thousands of thin pages.

## 18. Content quality

Every SEO page must satisfy at least one real user need.

Before creating a page, ask:

> If Google did not exist, would this page still be useful to a person?

If the answer is no, do not create it.

Avoid:

- Keyword stuffing
- Repetitive paragraphs
- AI filler
- Fake statistics
- Fake testimonials
- Fake reviews
- Fake author credentials
- Automatically generated low-value pages

## 19. Search snippets

Write titles and descriptions for humans first.

Do not stuff keywords into metadata.

The title should clearly communicate what the user will get.

The description should encourage a relevant click without making unsupported claims.

## 20. Page performance

SEO pages must load quickly.

Prioritize:

- Server rendering
- Optimized images
- Minimal JavaScript
- Proper font loading
- Lazy loading where appropriate
- Caching
- Small client bundles

Do not turn simple informational pages into large client-side applications.

## 21. Images

Images should have:

- Useful filenames
- Appropriate alt text
- Optimized file sizes

CV template previews should be optimized.

Do not use images merely to increase page size.

## 22. Mobile SEO

Assume a significant portion of users will arrive from mobile devices.

SEO pages must:

- Work on small screens
- Have readable text
- Have usable buttons
- Avoid horizontal scrolling
- Load quickly
- Keep important content accessible

## 23. Content freshness

Content should be reviewed when information can become outdated.

Do not display fake "updated" dates.

If a page is updated, update its date accurately.

## 24. Analytics and measurement

Prepare to measure:

- Organic traffic
- Landing pages
- Search traffic
- Builder starts
- CV exports
- Returning users

Important product events:

```text
organic_landing
builder_started
template_selected
cv_completed
pdf_exported
```

Do not collect CV contents as analytics data.

## 25. SEO funnel

The intended SEO funnel is:

```text
Google
  ↓
Useful article / template / example
  ↓
Relevant CTA
  ↓
CV Builder
  ↓
CV created
  ↓
PDF downloaded
```

The SEO system should support this journey naturally.

## 26. Expansion beyond Ghana

Do not hard-code SEO architecture around Ghana.

Eventually the product may support:

- Nigeria
- Kenya
- South Africa
- Other African markets

Potential future structure:

```text
/ghana/
/nigeria/
/kenya/
```

Do not implement country expansion until there is a reason to do so.

## 27. SEO implementation rule

Do not spend most of the development effort generating content before the actual product works.

Priority:

1. Great CV builder
2. Strong core landing pages
3. Template/example pages
4. Useful informational content
5. Measurement
6. Expansion

SEO should bring users into a product that actually solves their problem.

## 28. SEO definition of done

Before launch:

- Homepage has optimized metadata
- Main product pages have metadata
- Important pages have canonical URLs
- Sitemap works
- robots.txt works
- Important pages are indexable
- Builder/private routes are handled appropriately
- Open Graph metadata exists
- Heading hierarchy is correct
- Internal links exist
- Pages work well on mobile
- Pages load quickly
- No obvious duplicate/thin pages are intentionally indexed
